# حذف بک‌گراند بدون کادر توکن

این پروژه یک سرور آماده برای اجرای صفحه حذف بک‌گراند است.

## نکته مهم
کلید `FAL_KEY` داخل HTML قرار نمی‌گیرد. Fal هم برای برنامه‌های مرورگری توصیه می‌کند کلید در سمت سرور نگهداری شود. `fal.subscribe()` وضعیت صف را مدیریت می‌کند و نتیجه نهایی را برمی‌گرداند.

## استقرار روی Render
1. این ZIP را دانلود و در GitHub آپلود کن.
2. در Render یک Web Service از همین مخزن بساز، یا Blueprint موجود در `render.yaml` را استفاده کن.
3. در Environment Variables مقدار `FAL_KEY` را اضافه کن.
4. Deploy را بزن.
5. آدرس HTTPS سرویس را باز کن.

بعد از استقرار، صفحه خودش بدون کادر توکن کار می‌کند.

## توجه
من از داخل این چت نمی‌توانم یک دامنه عمومی را به حساب Render/Fal تو وصل کنم یا کلید خصوصی سرویس را به‌جای تو وارد کنم؛ این اطلاعات باید در حساب خودت بماند.
